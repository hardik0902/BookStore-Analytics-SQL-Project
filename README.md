📚 BookStore Analytics SQL Project
Project Overview

This project demonstrates SQL database design and business analysis for an online bookstore.

The database contains information about:

Books
Customers
Orders

The project includes data modeling, table creation, data querying, aggregation, joins, and business insights generation.
